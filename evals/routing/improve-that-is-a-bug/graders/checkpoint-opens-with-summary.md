PASS if the proposal Claude presents for the user's approval opens with a short summary in plain words - the problem or cause, what it proposes, and what the user must decide - before the detailed evidence, tables or ratings.
FAIL if it opens with details, evidence, a table or a list of priorities and the recommendation or the decision asked comes only after them, or if no proposal is presented for approval.
